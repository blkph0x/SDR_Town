# ICAO address-country allocation reference

`include/InmarsatIcaoCountry.h` transcribes range facts from
ibosoftnet/icao-aircraft-addresses, commit
`2ac0f294274beddb57212eb7531ff87dfd869de5`,
`Hexadecimal Addresses (Amendment 92).csv`:
https://github.com/ibosoftnet/icao-aircraft-addresses/tree/2ac0f294274beddb57212eb7531ff87dfd869de5 .

The adjacent LICENSE-CC0.txt preserves that revision's dedication:
https://raw.githubusercontent.com/ibosoftnet/icao-aircraft-addresses/2ac0f294274beddb57212eb7531ff87dfd869de5/LICENSE .
This is the transcription's dedication, not blanket permission for ICAO
publications or other datasets. SDR Town's original implementation has its
separate MIT terms. The package's embedded-inputs.json records the actual
source table hash; it does not prove an independent comparison of all ranges.

An address allocation is not an aircraft's current position, registration,
operator, nationality or authenticated identity. Unknown/unassigned and
special temporary/safety allocations remain unlabeled. Online positions and
user-imported information have separate provenance and are not bundled here.
