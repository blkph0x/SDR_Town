# SDR Town 0.2.131 experimental

## Satellite auto-capture no longer seizes the radio at startup

Opening SDR Town no longer jumps to SO-50 FM 436.795 MHz from a saved
**Auto capture selected sats in range** setting. That control must be checked
again this session before Satcom will take the Listen radio. Once you check it,
background capture still runs if you hide the Satcom dock.

P25 decoding, encrypted mute, and the Record Enc Grant IQ button are unchanged.

This remains an experimental tester build.
